# 移动 UI 精修审计

范围为现有八个模块的 114 页。每页按原稿、现有 HTML/CSS、图片与字体资源对照后修改；保留原来的信息架构和功能。复杂插画保持局部图片，交互与文案保持 DOM。

`queue.json` 记录这轮状态，独立于首次转换验收。`evidence/before` 保存修改前的 390px 截图、与原稿的对照图及五种手机宽度的指标；`evidence/after` 保存修改后的同类证据。`ui_audit.py --module N --phase before|after` 生成证据。

检验宽度为 320、375、390、414、430px。优先保持画板比例；当内容增长或安全区非零时允许页面滚动。交互反馈、键盘焦点和 safe-area 用小型共享 CSS，视觉位置与局部组件仍在各页维护，避免批量样式覆盖原稿差异。

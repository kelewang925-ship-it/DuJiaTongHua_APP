# 114 页 HTML 转换验收记录

本文件保留首次转换阶段的记录。后续逐页 UI 精修、五种手机宽度与全套复核的最终结论见 [UI 精修最终报告](ui-audit/FINAL_REPORT.md)。

日期：2026-10-04。分支：`codex/design-html-rebuild`。

## 已执行

- 114 张正式稿均有 `custom/{id}.html`，并生成对应的 `pages/{id}.html`；114 份原稿和 114 份去字素材齐全。
- 系统 Chrome 对每页分别以 390×826、862×1825 渲染，共 228 次；没有横向溢出、字体加载失败或页面脚本异常。
- 26 张并排缩略图覆盖 114 页，已将每页 HTML 渲染与原稿逐页目视对照。对照中补回了多处插画卡片、车票、照片和书页中被去字处理抹掉的文字，并修正相册网格裁切。
- 静态扫描找到 654 个原生控件；250 处 HTML 页面引用均指向本批存在的页面。回忆册最后 3 页的补页编辑、书签、改名、归档及确认弹层已在浏览器操作验证。
- 对 114 页的按钮做了逐个程序点击扫描，列出 36 个“点击后页面结构未改变”的结果，逐项复核原因。宠物房间的“已保存”已从按钮改成状态文字；邀请页增加了系统分享无响应时的即时提示和取消后的复制回退。创建账号、找回密码、重置密码、失败登录四个表单已使用有效输入验证。
- `python design-html/build.py --render-only` 与 `python design-html/audit.py` 通过，后者报告 `Handcrafted previews: 114`。

## 终验结果

- 第一次文字覆盖扫描在 40 页发现 OCR 与 HTML 字面量不一致；补齐 11 页确实漏掉的小字、标签或状态。再次扫描剩余 30 页、48 个字面量差异，已按原稿核对为 OCR 误读、简繁差异或插画装饰。明细见 `FINAL_RECONCILIATION.md`。
- 修订后再次完成 228 次 Chrome 渲染：无横向溢出、字体加载失败或页面脚本异常。工具报出的 6 条图片告警属于 3 个上传预览元素在双视口下重复计数；`m03-p11`、`m04-p04`、`m06-p02` 上传前没有 `src` 且 `display:none`、可见矩形数为 0。全量截图中无可见破图。
- 250 处跳转目标齐全。654 个原生控件经静态和点击扫描，36 条条件结果已复核；四个必填表单经有效输入测试。设计稿预览不连接真实业务接口，因此验证范围是页面内状态、路由和演示反馈。
- `review-queue.json` 的 114 页已标为 `text_and_controls: reviewed`。

逐页原稿对照、文字与控件终验已完成。手绘插画、纸纹和极小的插画装饰字仍是局部 WebP 素材；主要文案、表单和操作控件为可编辑 HTML。

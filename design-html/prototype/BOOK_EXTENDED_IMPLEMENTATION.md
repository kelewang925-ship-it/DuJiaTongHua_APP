# 回忆册专属编排、阅读工具和补页（第二批）

## 范围

替换p10～p12及p17～p20七页的旧脚本；p16接入相同真实阅读器，p13按每页实际模板打开正确编辑器。全21页现在使用统一册/章节/页ID和`dujia-prototype-books`。**只代表控制器接入，不代表回忆册或114页最终验收完成。**

## 实际页面行为

| 页 | 控件与结果 |
| --- | --- |
| p10 照片故事 | 共同照片选择，最多三张；替换/移除；焦点x/y和缩放1～2的裁剪Sheet，保存到页后阅读以同样参数显示；文字编辑、最多八个贴纸、真实图像预览；保存到p13 |
| p11 重要时刻 | 选择共同可见的真实时刻，标题/ISO日期、照片替换与一句话Sheet；没有实际时刻不能保存伪造页；保存到p13 |
| p12 工坊/宠物 | 两Tab选择真实ready作品或实际可见成长故事；换内容/照片/添加说明；空素材引导对应工坊或宠物入口；保存 typed source 与实际模板 |
| p16 阅读 | 真实标题、日期、独立文字/最新来源、三张图的裁剪、贴纸/寄语；可键盘滚动；原始来源跳转、上一/下一页、书签和阅读工具；存在补页时查看p20 |
| p17 工具 | 当前页上下文；全书目录、实际书签选择Sheet、添加补页、整理和管理；修正旧“书签→写补页”的错误路由；关闭回应或来源不可见时禁止新增补页 |
| p18 方式 | 当前实际页与正文；写几句话/表情/照片选择后携册ID、页ID和方式到p19 |
| p19 补页 | 空白输入、真实个人署名和演示日期；四种表情；图片类型/1.5MB/解码验证，读取中提交禁用；失败保留文字与图片，dirty返回保护；成功到p20 |
| p20 含补页阅读 | 原书页与实际多个补页/署名/日期/表情/附图；统一书签和阅读工具；不会用原稿伪造另一半回应 |

裁剪是保留原图的焦点和缩放渲染，不生成新图片、不修改原始相册。数据中保存照片引用及裁剪参数，阅读/导出重新读取可见图片。照片变私密后不显示或导出原图。补页图片实际存储data URL，不能以`photo:true`代替上传。

## 状态和隐私

- 统一读取禁用、提交busy、Toast、Sheet/Modal、root/Sheet dirty保护；写入失败没有新页/补页，已读/书签均按页ID。
- 实际工坊/宠物素材缺失时不保存示例来源；工坊空状态导向工坊，宠物空状态导向小屋。
- 日期使用共享Gregorian解析；照片页至少一张图，最多三张，裁剪数字范围校验。
- 每次保存重新查源；来源私密/删除后阅读及JSON导出遮蔽来源、照片和关联补页，保留用户独立编写文字。
- 补页遵守全局共同回应开关，直接调用仓库也不能绕过。
- 图片解码失败与本地保存失败可分别模拟`book-image`、`book-supplement`；原有book-create/theme/select/page/publish/bookmark/read/rename/archive/delete/export/load继续保留。

## 验证范围

- `verify_book_extended.py`：7项有名检查。三张专属模板按类型保存；实际照片裁剪/贴纸/正文→阅读；三种补页、失败重试；解码失败/dirty/保存失败；缺素材不伪造；照片私密后的阅读/导出遮蔽；未编辑返回和共同回应门槛。
- `verify_book_layout.py`：扩为21页×320/375/390/414/430共105项。真实可用按钮中心命中、水平溢出、安全区和脚本错误；本批重跑变化的八页，未变页沿用同一版本基础结果。
- `verify_book_image_variants.py`：p16/p20×五宽度共10项，三张实际图、裁剪、长独立正文、长补页/真实附图、解码完成与键盘滚动。
- `verify_book_flow.py`和`verify_book_states.py`第一批4+6项回归。合计132项有名册检查；不覆盖所有图片/文字/弹层状态组合，不是全产品最终验收证据。
- 首轮测试中直接fill/上传文件绕过弹层关闭动画/读取禁用，导致输入未生效；加条件等待以模拟可操作界面。空工坊错误显示宠物入口为实际缺陷，已由失败用例确认后修正。
- 截图检查发现素材照片层遮住p11日期/p12标题，以及p20仍露原稿示例照片；已调整实际图区域和遮盖，重跑相应宽度/长内容。

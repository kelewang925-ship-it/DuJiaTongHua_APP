# 恢复原始副本的页面入口

数据与存储页 → 存储空间管理 → 查看恢复原始副本 → 选择副本 → 下载原始副本。

复用既有按钮、Modal和Bottom Sheet，不增加页面或更改原稿画板布局。列表显示本机副本数量；每份副本独立下载。选择后再次读取内容，处理外部移除或修改；副本自身格式损坏时保留完整存储原文供下载。下载与关闭不会导入、恢复或覆盖当前记录。

这是本地恢复入口。原文可能包含私人内容，弹层明确提醒。普通“导出我的记录”和“共同记录备份”不包含这些原始副本；清理缓存保留副本，确认注销演示账号会清除副本。未提供历史副本删除、合并或自动导入功能。

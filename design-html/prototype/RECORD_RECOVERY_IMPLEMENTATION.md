# 本地日记与照片记录恢复

本阶段处理 `dujia-prototype-records`，仍为浏览器本地演示。其他存储集合、全部114页最终验收和原生Android行为继续开放。

## 复现与处理

- 原先坏JSON或错误根结构被当成空列表；数组中的null记录会使读取控制器报错。基线8项中7项失败，正常数据1项通过。
- 共享仓库按记录结构读取可读内容。无法读取的行、重复ID、标签和回应不会静默覆盖原始字符串；可读正文仍保留。
- 读取异常时显示共享Modal及“恢复记录”入口。可先下载实际原始JSON字符串，稍后处理，重新检查，或经第二次确认恢复。
- 原始字符串先保存到唯一的本地副本键，再替换主集合。副本或主集合写入失败均保留原始集合；主集合失败时已保存的副本仍在。
- 备份前和备份后各比较原始快照。发现其他页面的新内容时停止替换，保留新集合；这属于本地快照检查，不是跨进程数据库事务。
- 恢复后的刷新通过共享导航保护。未保存表单可继续编辑，输入保持不变，再次保存能写入恢复后的集合。重新检查已被外部修好的集合会安全刷新当前页面。
- 未恢复前，日记/照片写入和涉及记录的标签事务被阻止。标签事务先检查所有存储保护条件，避免先写标签再发现记录不能保存。

副本存储为 `dujia-prototype-record-recovery-<唯一ID>`，值是JSON编码的完整原始字符串。该阶段恢复弹层可下载恢复前的原始内容；随后已补齐历史列表/再次导出入口，见RECOVERY_ARCHIVES_IMPLEMENTATION.md。原始文件可能包含私人记录，仅供本地恢复，不属于共同备份或分享导出。

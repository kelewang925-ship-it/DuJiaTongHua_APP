## 数据与失败条件

`dujia-prototype-moments` 独立集合，项含 id/name/date/type/story/cover/related/createdAt/updatedAt/comments。关联记录保留在现有 `dujia-prototype-records`；删除时刻不删除它们。时刻评论含 id/text/author/createdAt/read，跟随本时刻持久化。

未初始化的时刻册/详情预览可以初始化“春日野餐”明确示例；注册初始化的空集合绝不补回。原单项 `dujia-moment-draft` 不作为发布集合使用。没有真实提醒、推送、跨用户通信。

`dujia-prototype-fail-next` 支持 moment-image/save/delete/comment/load。存储不足测试临时拒绝时刻集合写入，再恢复验证重试。

## 修复与证据

- P0：单草稿键与固定详情 → 稳定ID的创建/编辑/删除及列表/详情闭环。
- P1：关联按钮只有提示 → 实际共同记录选择、数据引用、详情导航和隐私筛选。
- P1：留言聚合固定内容 → 数据来源与原记录ID一致、已读状态持久化。
- P1：空关联选择无下一步 → 可创建日记或继续创建时刻。
- P1：列表无加载失败恢复 → loading/重试/刷新。
- P1：图片虽然解码成功，但超出封面框遮挡故事 → 绝对定位图片并裁切边界；新增边界断言，实施前失败→修复后通过。

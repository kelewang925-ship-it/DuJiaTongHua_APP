# 仅换图且仍在读取时的返回保护

## 问题与修复

P1 `IMAGE-PENDING-EXIT-01`：6个手动保存页面只选择图片时，图片值尚未更新，旧guard认为没有编辑，直接返回；6项原始检查均缺少未保存确认。

日记、照片、时刻、胶囊、个人资料和回忆册补页的guard现在同时比较已有reading／uploading标记。UI.guard增加可选onDiscard清理钩子：明确放弃时先取消对应图片请求，再commit未保存基线。继续编辑不取消读取；成功解码后的新图仍受未保存保护；失败且未产生有效修改时回到干净状态。

reading／uploading只参与当前编辑状态判断，沿用原有业务数据字段和保存落点。其他guard未传清理钩子时继续原有放弃行为。

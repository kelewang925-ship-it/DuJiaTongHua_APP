# 回忆册第四批：实际封面和主题

这是持续目标中的阶段进展，114页仍未完成最终验收。

## 实施

- 复用原册集合、typed照片引用、实际图片渲染与共享操作状态；没有另建封面存储。
- p05实时预览所选照片、书名和三种原有主题；保存后用于书架、目录及管理页。
- 花园午后、旅行手札、暖灯日常分别定义册内纸色、边线、墨色与强调色；目录、编排和阅读区域使用保存的主题。
- p21保留独立修改书名，并增加“修改主题与封面”；进入p05保存后返回当前册管理页，取消/未保存返回仍使用共享保护。
- 封面照片每次呈现重新检查来源，失效显示重新选择提示；保存前再次检查，失败保留主题与封面草稿。另一窗口将来源变私密时，预览立即遮蔽，未保存主题保留。
- 书架图片失败只显示进入册内重试提示，避免在书架按钮中嵌套另一按钮；其他封面采用现有图片重试控件。
- 动态封面覆盖原稿的封面内容区域，保留周围手账装饰。p15管理入口放在可滚动目录内，避免遮住封面或底部阅读入口。

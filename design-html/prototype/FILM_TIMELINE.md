# 影片片段时间轴与实际素材对应

P2-VIS-WORK-TIMELINE：m05-p05 只有一条素材或没有素材时，原底图仍显示1／2／3节点。旧渲染只把可用素材输出为文字按钮；另外按素材库的顺序过滤，未沿草稿保存的 `sourceIds` 顺序显示。

## 当前实现

- 仅这页加载展示辅助脚本与样式，以已有纸纹覆盖旧片段底图。投影仪／熊／标题、旁白、音轨、氛围及生成区域继续使用原插画和既有交互。
- 现有 `paintClips` 按保存的素材 ID 逐一寻找仍可共同访问的记录。展示辅助层为原按钮添加连续编号、类型、标题、日期及真实图片；无图显示原生纸页，有效图片请求失败显示占位。未选片段不增加节点，零条时有说明和原“选择共同片段”入口。
- 原按钮及“移除片段 标题”的可访问名称保留；新增编号和缩略图不增加操作目标。日期旁显示“移除”以说明点击行为，多条素材在片段区域内滚动，键盘焦点可到末项。
- 原选择器、数量限制、移除回调、未保存保护、草稿／生成、存储和权限检查保持。只有显示顺序改为草稿的 ID 顺序；本批没有增加拖拽排序或真实影片生成服务。
- 不可见的来源不渲染也不请求图片；现有生成检查仍会拦截包含无效来源的草稿，提示重新选择，不把受限内容变成可访问内容。

不把原稿的日落、旅行图或三只小熊自动填充为用户素材。本批是实际素材与时间轴一致性的修复及纸卡展示改善；原稿装饰精度、字体、其他工坊列表皮肤仍待，未宣称整页一比一或人工验收通过。

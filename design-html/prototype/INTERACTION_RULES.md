# 交互规则

这是当前HTML原型的共同契约与实际实现边界。每页入口/出口见PAGE_CATALOG.md；CURRENT_NAVIGATION.md是当前源码的回调候选，不能当作逐控件执行结果。NAVIGATION.md和CONTROL_BEHAVIORS.md分别记录本批实际导航与控件操作，其他条件分支仍待覆盖。模块实施记录提供已测试例子，全114页最终验收仍未完成。

## 操作契约

| 操作 | 统一规则 | 当前实现与未完成项 |
| --- | --- | --- |
| 点击 | 可点击对象必须有实际结果，图标有名称，重要热区≥44px；键盘可激活 | 原生Button、可点击Card、Tag与一级Tab使用原生控件；旧页面几何热区与每个隐藏状态仍需全量执行审计 |
| 一级Tab | 首页、时刻、工坊、宠物、我的，同名入口一致；切换不堆积历史 | primaryNav使用replace导航，当前项回到顶部；首页卡进入回忆册，不新增第六个Tab |
| 列表→详情 | 携带稳定ID，详情对应真实集合记录 | 日记/照片/时刻/纪念日/作品/回忆册模块控制器读取本地记录；来源过滤、失效和上下文按各模块判断 |
| 顶部返回 | 先关弹层，再处理未保存，最后返回来源或显式上级 | UI.back、guard、performBack；同源页面来源使用浏览器栈，无来源用fallback。领养完成页已有单独历史修复，其他多步骤任务仍需覆盖 |
| 浏览器返回/Escape | 弹层先关闭，不能同时离开底层页；表单变更应保护 | 原生dialog与同URLoverlay历史标记；浏览器popstate测试已有阶段证据。这里只模拟Android式语义，没有Android系统返回实测 |
| 未保存编辑 | 继续编辑保持原输入；放弃后才离开；保存成功重设基线 | UI.guard比较字段快照或模块值；UI.protectSheet在同Sheet显示继续/放弃，不叠加第二个dialog。正常连续操作已测，快速重复返回仍待专门核查 |
| 保存/提交 | 校验→Loading/禁用→实际写入→清dirty→反馈→按业务返回/显示结果 | UI.busy延迟550ms、aria-busy、防双击、finally恢复原按钮子节点；模块决定写入及落点。失败不能调用成功导航 |
| 损坏记录恢复 | 原始内容可下载；确认后先保存原始副本再恢复可读记录；并发更新或写入失败停止替换，刷新遵循未保存确认 | 日记/照片及个人/关系资料已接入；个人/关系异常时普通保存暂停，原始副本和确认恢复保留入口。副本历史下载已补齐；其他集合继续实施 |
| 输入错误 | 具体说明、错误关联字段、聚焦首错；修改后清错 | 共享field与fieldError；旧模块有自己的字段提示。所有表单blur、超长输入与键盘状态尚未逐项统一 |
| 取消选择 | 取消/Escape/遮罩/下滑不提交候选；确认才回填 | UI.sheet返回所选value；取消null，Modal取消false；模块控制选择提交时机 |
| 删除 | 重要内容使用明确确认；取消不改变记录；成功更新实际列表 | 各模块已有确认与稳定ID删除。危险确认按钮仍有调用使用默认primary，需要逐项迁移DangerButton；尚未实现统一撤销系统 |
| 加载失败 | 保留上下文，显示原因和重试/返回，失效内容不能当成新建 | 日记/照片/时刻/回忆册实际失效页已使用共享ErrorState；回忆册加载失败禁用底层任务控件，成功才恢复。其他模块状态仍需接入 |
| Toast | 简短非阻塞，用于成功或即时反馈；不能代替数据操作和危险确认 | UI.toast支持success/error/info，2600ms；真实分享/通知等只描述本地演示，不声称已发送 |
| 开关/勾选/收藏 | 更新实际状态与可访问属性，刷新后按产品契约保留 | 共享Tag使用aria-pressed；模块业务状态由本地存储管理。逐控件“点击后再刷新”审计仍在进行 |
| 长按、滑动、刷新、分页 | 仅有业务意义时使用，不给所有列表强加手势 | 当前简单点击/更多菜单优先；列表是否需刷新、分页的最终逐页适用表待补全 |

## 已明确的首次入口与日记上级

关联成功页保留写第一篇日记／完善资料，并增加“先逛逛我们的首页”；实际昵称和日期从刚保存的数据回显。新增出口替换成功页进入实际空／正常首页，不以预置内容绕过空态。日记列表标示“返回首页”的顶部按钮明确导航到首页，日记详情顶部明确返回日记列表，避免返回已完成的编辑任务；列表筛选session条件保留，编辑器未保存返回仍走guard。浏览器原生历史的其他路径仍待专项覆盖。

## 弹层规则

- Modal用于决策、确认和需要阅读的内容；Bottom Sheet用于局部编辑、菜单、筛选和选择。完整多字段任务沿用原设计的页面序列。
- Modal宽度屏宽−32px、max360px、圆角20px、max85svh；Sheet宽度max431px、顶部圆角20px、底部安全区、内容可滚动。两者沿用共享组件，禁止另建相似弹层。
- 原生showModal隔离底层操作；Tab焦点循环，关闭恢复原触发控件。双动作Modal首先聚焦取消，Sheet首先聚焦第一个可用行动的细节仍需检查所有disabled组合。
- 点击遮罩、Escape、取消、浏览器返回通过同一个关闭函数；Sheet拖动条向下超过80px也调用它。beforeClose拒绝时恢复弹层历史位置。
- 未保存Sheet使用同弹层警告，继续编辑恢复之前焦点，放弃后关闭。不要仅隐藏表单而残留拦截页面的遮罩。

## 数据与失败边界

未初始化集合与空集合按首次无内容处理，不自动植入示例。业务集合稳定ID串联列表/详情/编辑；localStorage用于原型演示。异步和失败来自有限本地延迟、failNext及浏览器容量/图片解码，不是真实服务。

UI.read对JSON解析失败返回fallback；这还不足以证明破损数据可恢复，合法JSON但字段类型错误仍待修复。禁止以自动清空存储作为恢复方案，也不能把调用了函数等同于动作已成功。详细状态与恢复证据见STATE_RULES.md；动效见MOTION_RULES.md。

## 登录、邀请与临时验证码异常

登录/邀请损坏沿用原始下载、确认副本与恢复前暂停保存规则；损坏会话恢复后退出登录，重新登录。临时验证码异常保持原文并提供注册/找回出口；只有用户明确获取新码才替换。验证码必须用途一致且未过期。缺失挑战重发与未准备邀请不给成功反馈。范围与证据见SESSION_INVITE_IMPLEMENTATION.md。

## 时刻回应未发送保护

回应Sheet在取消、Escape、浏览器返回或拖动关闭时，输入改变需先确认是否放弃。继续编辑保持输入与焦点；确认放弃不改变记录。发送失败保持内容，发送成功追加回应后提交dirty基线并关闭。使用共享protectSheet；此证明范围是时刻回应，不涵盖其余全部Sheet。见MOMENT_CONTROL_EXECUTION.md。

## 日记与照片详情回应

未发送回应离开详情页（返回按钮/浏览器历史返回）复用guard，先确认继续编辑或放弃；失败保留输入与记录，成功清空并commit，关闭回应时输入/发送/表情均禁用。日期回退与caption搜索范围、控件和五宽度证据见RECORD_CONTROL_EXECUTION.md；其他表单、引用/格式和原生平台条件继续验收。

共享浏览器历史guard在弹出未保存确认前恢复保护节点；继续后关闭过渡中的再次返回可以保持当前编辑或出现新确认，但不得离开页面或丢失输入。稳定后确认放弃才进入实际列表。日记/照片各3次独立场景，每场景重复3轮快速继续/返回，见record-back-reentry-results.json。

### 胶囊收录的一致性

把开启的胶囊收录为重要时刻时，胶囊的momentId与新增时刻用已有本地transaction一起更新。任一写入失败，保持原内容与当前页面并提示重试；成功进入稳定时刻ID；再次收录复用原时刻。当前支持的写入失败与回滚场景见TIME_CONTROL_EXECUTION.md。

### 工坊共同素材与主角返回

共同创作选择器只提供可共同使用的内容。日记/照片使用共同已发布记录；重要时刻排除visibility=private或status=draft，正常历史时刻无这两个字段时继续可用。主角设定页有有效work参数时返回原作品编辑器，按钮读作“返回当前创作”；独立入口返回童话工坊。字段仍遵循现有未保存保护。

### 设置编辑弹层与异步结果焦点

共用设置edit()以protectSheet保留未保存输入：取消、Escape、浏览器返回、下滑都要先决定继续或放弃；继续保留输入与焦点，放弃不写入。保存失败继续编辑；成功commit后关闭。异步检查版本先恢复触发按钮可用与焦点，再打开结果Modal，关闭后焦点回触发按钮；检查失败提供Toast与原按钮重试。

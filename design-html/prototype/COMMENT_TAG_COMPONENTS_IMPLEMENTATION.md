# 留言头像与标签组件接入

日记/照片的动态留言作者行采用现有Avatar，仍显示可读作者文字。头像对辅助读屏隐藏以避免重复姓名；缺失作者按访客显示，不改变存储。共用author行布局和间距Token。原消息、输入保护、重复提交、防失败保存与重试回调保持。

Tag新增动作模式`selected:null,onActivate`，没有aria-pressed也不切换选中状态，用于标签管理编辑/删除菜单。默认selected/onChange模式保持原来的选中切换；不把管理菜单伪装成选中控件。标签管理的个人/共同分组之间使用现有Divider；原纸张皮肤和局部标签外观保持，不能据此宣称局部Token全部迁移。

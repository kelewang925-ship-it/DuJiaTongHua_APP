# 关闭书库后同步书架

修复 P1-BOOK-SHELF-RETURN-STALE。另一窗口更新数据时，已打开书库的分类列表已同步，但底层书架仍使用最初的册列表。关闭菜单后书名、册数、页数、上次阅读位置和选中册可能过期；删除或归档最后一本也未进入空书架。基线7个实际返回场景全部失败，无脚本异常。

## 实现与范围

复用书架现有数据源与渲染，只在取消／关闭书库后重读最新已成册列表，重绘册封面并更新计数和阅读位置。仍存在的选中册按稳定ID保持，已移除时使用当前位置可用册；没有已成册内容时进入现有空书架，并保留新建入口。Header和菜单触发器保持原节点，普通取消仍恢复焦点。

书库增加可选关闭回调，点击书目时先标记正在打开，避免关闭回调抢走既定管理／编辑／阅读导航。不增加全局监听、业务数据写入或状态框架；存储、编辑器、阅读器、HTML和CSS均保持原字节。旧封面节点的注册项在重绘时清理。

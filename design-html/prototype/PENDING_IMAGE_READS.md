# 保存等待期间换图

## 问题与修复

P1 `PENDING-IMAGE-READ-01`：点击保存后选择新图片，FileReader／图片解码尚未完成，guard的图片值仍是旧值。仅比较图片值的等待任务会继续写入旧图或空图，再离开编辑页。日记、照片顶部完成、个人头像和回忆册补页的8项基线均复现迟到写入。

共享UI增加文件选择change事件的捕获处理：用与UI.busy相同的submissionScope识别页面guard根节点或dialog表单，立即取消其仍在等待的任务。随后由各页已有reading／uploading状态阻止再次保存；读取完成后必须明确重新保存。成功保存新图；解码失败保留原图和输入，重试保存原内容。

# 回忆册第六批：跨模板书页草稿

本批为持续目标的阶段进展，114页仍未完成最终验收。

## 草稿规则

- 日记摘录、照片故事、重要时刻、工坊作品、宠物成长使用同一个轻量会话草稿契约。点击换模板先暂存，再进入选择页，不需要放弃已有编辑。
- 会话键`dujia-prototype-book-editor`按随机token隔离；每项绑定册ID、稳定书页ID、独立文本/日期/寄语、照片引用/裁剪/贴纸、按模板保存的来源引用和编辑前书页快照。
- 切换后恢复完整数据；选择来源所需的模板仍要求实际可见素材，不能用其他类型的来源假冒。未选择素材的模板默认文字不会自动变成用户独立编写文字。
- 重要时刻重新选择来源会更新可见标题/日期，同时移除旧的独立标题/日期；其他未改变的独立字段保留。
- 新页第一次暂存分配稳定ID，之后保存只生成一页；已有页始终更新原ID。另一窗口修改或删除同一页时拒绝覆盖，保留当前输入。
- 暂存失败停留当前编辑页并保留输入；保存失败可重试。恢复的草稿仍受未保存返回保护；继续编辑保留，放弃或成功保存清理该会话条目。
- 放弃新页后清理模板页中过期页ID，可继续新建；已删除页的旧编辑入口返回整理页，避免隐式重新生成被删除内容。
- 册间token不通用；草稿只在当前浏览器会话内保留，不作为已发布册、全局备份或长期草稿。暂未提供会话草稿目录和冲突合并界面。
- 章节扉页属于独立章节操作。带未保存书页草稿的模板选择页禁用此项，并提示先完成书页再在整理页新增章节；新建流程仍可添加章节。

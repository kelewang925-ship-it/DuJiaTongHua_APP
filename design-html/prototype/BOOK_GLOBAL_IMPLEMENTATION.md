# 回忆册第五批：备份、草稿箱与首页阅读

持续目标保持进行中；114页均未完成最终验收。

## 数据和交互

- 将册来源解析、书页呈现数据和导出脱敏移到已有PrototypePreferences的共享契约，PrototypeBooks复用这些接口。设置页不必加载宠物页面控制器即可解析宠物成长与来源权限。
- `snapshot().books`包含本机册和册草稿；共同备份只包含published册（含归档），不把未完成草稿当成已发布内容。
- 备份、全局导出和册内导出使用同一bookExport，重新核对日记/照片/时刻/工坊/宠物来源。来源不可见时隐藏关联正文、图片和补页，保留用户独立编写文字。
- 册写入/删除触发已有自动备份；来源记录权限变化也更新备份。共同备份中的工坊作品须仍有共同可见来源；失效作品不会因原先ready状态继续被复制。
- 草稿箱增加实际回忆册草稿，携册ID到建册页继续编辑。
- 首页阅读卡显示实际未归档册；有有效阅读位置时携页ID继续阅读，否则进入目录。没有册时提示创建；长名称使用省略显示，完整名称保留在title和DOM文本中。
- 退出登录保留册及草稿；注销演示账号成功后清理册；注销失败保留原数据。没有接入真实账号或服务。
- 无效工坊时间及不存在的关联纪念日不进入册来源，避免破坏备份。异常册结构的完整恢复界面仍待实现。

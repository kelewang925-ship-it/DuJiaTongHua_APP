# 回忆册实施记录（第一批）

## 范围与当前边界

本批将p01～p09、p13～p16、p21共14页连接到统一册集合。首次空数据、空白建册、真实共同日记编排、目录/阅读、书签、改名、归档、导出和稳定ID删除有可重复流程证据。**不是回忆册21页完成**：p10～p12以及p17～p20七页仍为旧实现，照片/时刻/工坊/宠物专属编排和补页必须继续替换；p08这些版式的出口目前仍进入旧页，尚未形成闭环。

## 统一数据

- `dujia-prototype-books`：按稳定册ID存储；每册包含name/dates/start/theme/coverPhoto/status、chapters/pages/selected、bookmarks/lastPage/archived和时间戳。
- 页ID、章节ID和来源类型/ID独立，不用书名或来源标题作为身份。原始日记不会被编排操作修改；同名不同册删除互不影响。
- `PrototypeBooks`负责本地集合、来源读取、草稿、页面/章节保存、阅读/书签/补页/导出接口。原有`fairy-memory-*`键不推断为完整已建册，暂不自动迁移。
- 来源读取共同已发布日记/照片、共同时刻、ready工坊、当前宠物可见故事；按册月份范围过滤。工坊引用来源需要仍可见。五类来源接口已具备，当前浏览器闭环只验证了日记，其他类型必须继续验证。
- 未编辑的正文不复制入册，阅读与导出读取当前来源。用户明确编辑的独立文字保存；来源变私密后遮蔽原正文，保留独立编写文字，不导出关联补页。
- 读取400ms期间控件禁用，避免初始化覆盖过早输入；提交550ms防重复，失败保留当前输入及原集合。
- 尚未将册接入全局备份/自动备份、聚合草稿和首页继续阅读，也未验证多窗口同册并发修改；这些不属于本批已通过范围。

- `verify_book_flow.py`：4条主流程，首次空页、空白建册到书架/刷新、真实日记到出版、删除后不重植示例。实施前4条全部失败，当前结果见`evidence/current/book-flow-results.json`。

- `verify_book_layout.py`：本批14页×320/375/390/414/430，共70项水平溢出、安全区、控件中心命中、脚本错误及截图。没有检查所有文字/图片/弹层组合，不能代替最终视觉验收。

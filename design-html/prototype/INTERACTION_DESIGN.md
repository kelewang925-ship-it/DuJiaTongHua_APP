# HTML 完整交互原型设计与验收规范

## 1. 范围与实施方式

保留 `custom/` 为源、`pages/` 为预览的生成方式以及全部 114 张原稿的视觉语言。静态状态稿继续可从目录访问；正常流程根据模拟数据决定正常态/空态/失败态，不能把画册目录当作产品导航。

实现选择：**在原页面上增加轻量共享 JS 与逐模块控制器**。逐页复制弹窗和存储逻辑会继续造成不一致；改成新的 SPA 会扩大本轮范围并牺牲已经验证的页面。共享层仅负责反馈/弹层/导航辅助/本地 JSON 读写/可控异步演示，具体业务与 DOM 绑定由模块控制器负责。保留成熟的既有处理代码，不同时绑定两个提交或点击行为。

所有新增需求从本轮提示词和现有页面推导，不增加聊天、付费或新产品模块。异常、首次和空数据演示入口放在原型评审工具中，正常产品页面不展示技术参数或测试按钮。

## 2. 页面类型与导航

| 类型 | 规则 | 页面实例 |
| --- | --- | --- |
| 一级入口 | 统一 Bottom Tab，切换时不累积返回栈；保持同名 Tab 目标一致 | 首页、重要时刻、工坊、宠物、我的；回忆册由首页阅读卡进入 |
| 列表/详情 | 列表卡片携带内容 ID，详情返回原列表及条件；编辑返回原详情 | 日记、照片、纪念日、作品 |
| 完整编辑任务 | 使用 Push，分步骤任务维持已有页面序列 | 日记、上传照片、新建册、角色设定 |
| 局部选择/更多 | Bottom Sheet，在当前任务保留草稿与上下文 | 筛选、日期/标签/分享/更多操作 |
| 决策/危险确认 | AppModal；取消为默认安全动作 | 放弃编辑、删除、退出、解除关联 |
| 无数据/错误/生成中 | 沿用对应状态稿或内容区域内状态；始终提供返回/恢复路径 | 首次领养、空相册、生成失败 |

详情不能直接进入新建编辑器而不传记录。不存在内容时提供“返回列表”和合理解释；从目录直接打开深页有固定 fallback，不依赖不存在的浏览器历史。

### 返回优先级

1. 关闭正在打开的选择器/Bottom Sheet/Modal，并恢复触发控件焦点。
2. 有未保存变更则确认“是否放弃当前修改？”：继续编辑/放弃修改。
3. 返回当前任务的来源页面；无来源时使用显式上级。
4. 一级入口不返回到其他 Tab 的历史串。

HTML 验证顶部返回、浏览器返回和 Escape；Android 系统返回的 RN 映射记录为同一规则，不能声称已经在 Android 原生端完成验证。编辑 dirty 只比较用户字段和选择，不因自动加载默认值产生误提示；保存成功后清除 dirty，失败保留。

## 3. 数据与异步模拟

使用现有 `dujia-*`/`fairy-*` 数据键，明确区分临时草稿、已发布内容和页面选择状态。必要的新集合集中在少量本地键中，集合项有稳定 ID；列表、详情、搜索、编辑都读取同一集合。

- 未初始化与空集合都按无内容处理；打开页面或编辑器不自动写入示例。正常态通过实际创建内容或显式评审fixture展示，不将首次用户默认视为已有数据。
- 保存先校验，再显示 400–800ms 的有限 loading，防重复提交；成功才持久化、反馈、返回并显示内容。
- 失败模拟不能悄悄写入成功数据，失败后保留输入并允许重试；模拟恢复可控，无真实请求。
- 文件保存用于演示预览，明确容量限制，处理浏览器存储写入失败；不能把仅当前页有效的 blob URL 当作永久上传。
- 普通删除可使用确认并在成功后刷新集合；重要记录、关系、宠物、整册必须确认后执行本地演示删除。不可在取消时删除数据。
- 模拟登录只保存演示身份状态，不保存真实密码，不冒充真实验证码发送或第三方分享完成。

## 4. 状态适用规则

| 场景 | 必须包含 | 恢复/下一步 |
| --- | --- | --- |
| 内容型首页/列表 | normal、首次 loading skeleton、empty、load error | empty 创建 CTA；error 重试；有意义时刷新 |
| 搜索 | 未搜索、结果、无结果、loading/error | 改关键词/清条件，保留输入 |
| 图片 | 占位、加载完成、失败 | 重选/重试；保留说明和可见性 |
| 表单 | initial、focus、typing、filled、disabled、field error、submitting、success/failure | blur 后具体错误，首个错误聚焦，修改后清除错误 |
| 生成 | 进度、取消、成功、失败/超时 | 返回编辑保留素材；失败重试；完成作品进入历史 |
| 选择器 | 初始、选中、不可用、确认/取消 | 取消不提交选择；确认后回填 |
| 列表末尾 | 根据数据量判断是否分页 | 没有真实分页需求时显示完成，不添加无意义加载 |

所有列表都需要 empty。所有**有模拟异步行为**的动作需要 loading/error；纯文本说明、静态条款、即时开关不强行增加 Spinner。表单错误优先字段提示，保存/复制成功用短 Toast，删除或未保存决策使用 Modal。

## 5. Design Component System

以 `docs/design-system/` 既有 Fairy Token/Navigation/Forms/States 为来源，本轮提示词的温暖、轻盈、克制动效优先于旧文档中的复杂插画循环动画。现有原稿布局定位值保留；新增组件布局与间距使用统一 Token。

| 组件 | 尺寸/外观 | 状态 | 交互 |
| --- | --- | --- | --- |
| PrimaryButton | 新组件高48px，原稿既有按钮保持比例；热区≥44px，奶油/桃粉，可可字 | default/pressed/disabled/loading | loading禁止重复提交，保留可访问名称 |
| SecondaryButton/TextButton | 次级浅色/文字，热区44px | default/pressed/disabled | 安全取消、返回、次要操作 |
| IconButton | 图标20–24px，热区44×44px | default/pressed/disabled | 有 accessible name，不能只使用图标 |
| DangerButton | 明确危险文字/低饱和警示色 | default/pressed/disabled/loading | 危险确认中使用，不能默认聚焦 |
| AppInput/Textarea | 新组件48px高/多行最小96px，8px圆角，内边距12px | focus/filled/error/disabled | 关联Label和错误描述，键盘可操作 |
| AppCard | 16px内边距，12px圆角，纸色及细边框 | default/pressed/selected | 只有可操作卡片呈现按下反馈 |
| AppHeader | 新组件56px+顶部safe area，图标热区44px | 普通/透明、可选右侧动作 | 返回遵循优先级 |
| AppModal | 屏幕宽度−32px，max360px，20px圆角，可滚动内容 | alert/confirm/content/open/closing | 遮罩、Escape、焦点循环、取消、焦点恢复；危险选择明确 |
| BottomSheet | max431px，与App画布对齐，顶部20px圆角，拖动条36×4px，最大85svh | open/selected/closing | 遮罩/取消/下滑关闭，内容滚动，底部safe area |
| AppToast | 简短最多两行，底部导航之上，2–3秒，非阻塞 | success/error/info | live region，关键按钮不被遮挡 |
| EmptyState | 既有小插画/原生图标+标题+说明+CTA | 无数据/无结果 | 下一步可直接操作 |
| Loading | 列表骨架/按钮loading/生成进度 | 有限时长、可取消长任务 | 不全部使用Spinner |
| ErrorState | 说明+恢复按钮，颜色柔和 | 网络/图片/保存/生成 | 保留输入和选择，可重试 |
| Avatar/Tag/Divider | 头像保留原稿；Tag紧凑圆角；Divider细暖色 | Tag selected/disabled | 仅交互型Tag可聚焦 |

### Token 基础

- 颜色：复用纸色 `#FDFBF7`、主文字 `#6B4F4F`、强调 `#B08A8F`、桃粉 `#F6BEC8`、边框 `#D4BDB6`；不重新调全页颜色。
- 字体：本地 Fairy 字体及已有数字字体；新组件标题20px/正文16px/说明14px。
- 间距：4/8/12/16/24/32px；圆角8/12/20px；阴影仅弹层与抬高卡片。
- safe area：复用 `--ui-safe-top`/`--ui-safe-bottom`，新增弹层单独避开键盘和底边。

## 6. 动效

| 对象 | 规则 | 时长 |
| --- | --- | --- |
| 页面 | opacity与translateY 8px，轻微进入 | 220ms |
| 按钮/卡片 | opacity .8或scale .98；不大幅弹跳 | 120ms |
| Modal | 遮罩淡入，scale .96→1 | 220ms |
| Bottom Sheet | translateY 100%→0，ease-out | 280ms |
| Toast | 轻微淡入淡出 | 160ms |
| 收藏 | 仅实际状态切换轻微scale1.15 | 180ms |

统一遵守 prefers-reduced-motion：取消位移缩放和无必要循环，保留状态反馈。关闭完成后卸载弹层而非残留透明点击层。

## 7. 测试要求与交付

先针对确认的流程断点写浏览器回归，再修改对应页面。每个模块至少测试成功、输入错误/缺数据、取消、失败恢复、刷新后持久化以及正确返回；关键创建流程测试跨页读写，不能仅断言 Toast 可见或 localStorage 有一个键。

全套验收应包含：114页访问/资源/脚本、653节点逐个行为契约及运行时检查、导航触发控件和条件、首次与空数据主流程、模拟断网/图片/提交/生成失败、弹层键盘/返回/遮罩/手势、五种手机宽度与safe area、原稿并排截图。模拟真实API的测试不等于真实后台验收。

最终输出：PAGE_CATALOG、NAVIGATION、CONTROL_BEHAVIORS、COMPONENTS、INTERACTION_RULES、STATE_RULES、MOTION_RULES、ISSUES与FLOW_TEST_REPORT；文档必须区分已实施、验证通过及剩余项，全部闭环完成后才标记目标完成。

## 已实施范围

- m08-p01～p21 共 21 个页面保留原有路由，改为语义 HTML 和回忆册局部样式。正文、表单、标题和按钮均可编辑，不用整张概念图代替页面。
- 书架：布纹封面、书脊与纸边、横向 scroll-snap、相邻封面预览、滑动/键盘/按钮选册；名称、页数、进度与入口同步；全部册、草稿和归档复用现有集合。
- 阅读：同一个 DOM 场景内翻页；实测纸面高度后生成长文、寄语与图片续页，保存兼容原 `lastPage` 的文本/块锚点；竖屏单页、空间足够时横屏双页，系统旋转锁仍由系统决定。
- 翻页：12 段 CSS 3D 曲面、正反面内容、阴影、跟手拖动、完成/回弹；开合封面；上一/下一页和键盘替代操作；减少动态效果时即时切换。
- 阅读工具：章节/缩略图/书签定位，大字连续阅读与字号切换，照片独立放大查看，真实补页入口及署名/日期/照片显示。关闭共同回应或来源不可见时展示原因。
- 整理：章节化双列缩略图、长按触摸/桌面拖放、上下移动和跨章菜单、移除确认；操作先保留在候选排列，保存后才写入；从阅读进入整理后保存返回原阅读位置。
- 建册、封面/主题、选材、模板、五类书页编辑、完成、目录、补页和管理均使用统一皮肤；编辑预览随内容变化，输入和工具保持原数据契约。
- 复用既有来源解析、图片裁剪、模板会话草稿、失败重试、未保存保护、跨窗口冲突、备份、归档与导出脱敏。来源转私密后清除当前纸面、封面、整理缩略图与补页的关联展示。

## 验证与证据

原V2实施版本检查：159 项浏览器场景全部通过（11 项 V2、7 项集成/触摸/动效、106 项布局、35 项原有业务回归），另有 21 组页面一致性和五个 JS 语法检查通过。

原实施版本的执行结果、源码哈希和时间以 `evidence/current/book-v2/verification-summary.json` 为准；未生成或 `passed` 不为 true 时，不构成最终验证通过。

- `verify_book_v2.py`：书架选册、同文档翻阅、书签/重载、长文、大字、取消拖动、目录、隐私、封面隐私、长寄语及整理返回。
- `verify_book_v2_integration.py`：三种真实补页/失败重试、多图与长文跨续页、正常动效的曲面连续性、横竖屏/双页边界、CDP 触摸书架/阅读和封面开合。
- `verify_book_v2_layout.py`：21 页 × 320/375/390/414/430，共 105 个布局场景，另有 844px 横屏阅读；检查横向溢出、实际按钮/字段中心命中、脚本错误和纸面溢出。
- `verify_book_v2_regressions.py`：隔离运行原有建册、状态、章节排列、模板草稿、专属编辑/补页、全局备份测试，输出保存在本批目录，不覆盖旧批次证据。专属编辑测试的补页入口已随 V2 UI 更新，保留原三补页、失败和保存断言。
- 21 组 `custom/pages` 内容一致、所有资源存在、五个相关 JavaScript 文件语法与限定 diff 检查。

旧 `verify_book_image_variants.py` 针对单页滚动容器和同屏三图的断言不再适用；其对应功能改由 V2 集成测试逐续页累计图片、正文并检查无遗漏。没有为了通过旧断言而取消分页。

## 独立审查与修复

独立审查曾实测发现封面私密刷新、跨阅读模式锚点丢失、长寄语截断三项问题，均已修复并由独立浏览器上下文复核。另核对触摸阅读、目录跳转及整理长按/菜单共享候选排列；审查未发现新的交付阻断项。

最后触摸测试还暴露了首次布局观察会取消刚开始的手势：改为初始排版完成后再观察尺寸，并在加载期间等候字体。测试保留了触摸事件轨迹，不能仅用鼠标通过代替触摸结论。

## 实际边界

以上为 Chrome 手机模拟、真实浏览器触摸事件、源码及页面截图验证。没有真实手机硬件、Safari 或 Android WebView 的性能验收证据；不承诺所有设备 60fps。人工视觉验收仍由用户完成，不改写原型 114 页的最终验收标记。

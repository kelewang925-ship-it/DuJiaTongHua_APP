# 日记、照片、回忆册共享状态（阶段记录）

## 接入

- 日记编辑/详情、照片编辑/详情的内容失效页使用共享ErrorState：明确原因、稳定可访问名称、恢复CTA；保留原页面容器和实际空/正常列表路由。
- 回忆册p04基础信息编辑链接携带失效ID时，显示失效状态，不被默认为新建；p05～p21同样使用明确失效说明和“返回书架”。旧页面控件被隐藏，不能执行过时操作。
- 回忆册的blank辅助函数使用共享EmptyState，保留各场景原说明与创建操作。
- 回忆册初次加载使用共享Skeleton；失败使用共享ErrorState及重试/返回书架。在失败期间保持底层任务控件禁用，成功重试才按首次状态恢复并绑定当前控制器。

失效册的行为明确从“立即自动跳转”改为“说明 + 用户选择返回”，这与日记、照片、时刻一致。主流程删除完成后仍按既有代码返回书架，不被改为失效提示。

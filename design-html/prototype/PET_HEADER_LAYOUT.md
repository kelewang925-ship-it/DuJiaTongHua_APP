# 任务／设置页的完整姓名与头像避让

本批修复 P2-VIS-PET-INLINE 的 m07-p11、m07-p25 标题、双人称呼和宠物名子范围。上一批名称已正确插入，12字宠物名仍进入宠物／更多按钮区域，双人长名进入头像。个人资料当前允许20字昵称，宠物改名允许12字，本批保留完整文字，不删字或以省略号隐藏问题。

## 两页布局

- p11标题限制在返回与右侧宠物之间，允许完整换行。两位照顾者分别显示在头像下方的两列中，姓名可以独立换行。保留原头像、宠物与纸张语言，裁去旧Tab底图，任务Tab和每日／本周滚动区域下移，底部返回仍保留。
- p25标题在返回与“更多”之间居中换行；宠物名沿照片下方小铭牌区域居中，长名形成两行。双人称呼和照顾天数放入同一正常流容器，天数随姓名高度下移，不跨头像或卡片边界。
- 只增加两页局部CSS与姓名分组标记，同步custom/pages。所有JS、共享CSS、图片／字体、状态／存储、任务、开关、改名、导出及返回回调保持原字节。姓名插值继续复用上一批辅助层，不新增姓名状态或业务逻辑。
- p11为最长合法姓名预留顶部区域；任务列表继续在其自身区域滚动，不挤占底部操作。未把原四行静态任务、图标或奖励当成当前实际五项任务，这些动态卡片的完整原稿皮肤仍另有P2待办。

## 基线与结论边界

原实际几何合同40项中5通过、35失败；通过的是p25短名五宽度，未把它们说成旧缺陷。失败均在标题进入宠物或更多区域首先触发，后续姓名／头像检查仍单独保留在合同中。原源、生产脚本、截图及精确补丁保留于 `evidence/baseline/pet-header-layout`。

更早的探索脚本要求姓名必须处于新的下方分区并出现新标记，40项均失败。这不等于40个真实旧遮挡，已保存于 `pet-header-layout-before-avatar-contract`；在修改产品前，先把合同改为实际头像矩形相交、文字完整及可操作边界，允许原p25短名布局通过，然后才形成5/40实际基线。

本批只关闭这两页已复现的姓名避让子范围。p01／06／10／13／16／19／21／22等其他P2-VIS-PET-INLINE范围、字体和动态卡片皮肤仍继续；不是全部宠物页面或114页的视觉／人工验收通过，人工仍0。上一批104项名称报告保留原源指纹，不冒称本次重跑了全部25页名称。

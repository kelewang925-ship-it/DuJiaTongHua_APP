# 回忆册第三批：多素材队列与章节编排

本批属于持续交互原型目标的阶段进展；114页均仍为部分实施，0页完成最终验收。

## 行为

- p06保存选择后，p07只展示尚未入册且未跳过的素材。p13提供“继续编排 N 份素材”；已保存页不会重复进入队列。
- p07跳过一份素材后继续下一份；全部处理后进入p13。来源私密或删除时禁止入册，可跳过或重新选择；失败保留队列，不生成示例书页。
- p13章节操作Sheet支持改名、前后移动、确认删除。删除章节时说明包含多少页，原始共同记录保留。
- p13书页操作Sheet支持章内排序、选择目标章节、确认删除。操作保存在当前编排草稿，只有“保存排列”才写入册。
- 保存排列同时整理跨章页序、清理删除页的书签和阅读位置、移除被删除页对应的选中素材；删除的页面不会被队列自动重新生成。
- 写入失败保留本地排列并可重试；返回仍使用统一未保存确认。
- 同册另一窗口保存后，本窗口保存时核对updatedAt，拒绝覆盖并保留本地修改。暂未提供冲突合并或本地排列下载功能。

# 动态列表共享Card接入

## 工厂与页面

既有components.card增加可选content（DOM节点数组）。默认null仍按原title/message生成h2+p；指定数组则保留节点及顺序，之后也可append图片、正文和元信息。onClick仍决定原生button/article，交互卡type=button，selected仍使用aria-pressed。没有字符串HTML解析，没有新状态层或导航架构。

13处实际渲染器已复用该工厂：主页近期记录、搜索结果、日记列表、相册、时刻册、纪念日行、共同提醒、胶囊、工坊近期作品/我的创作、草稿箱、宠物时间线和留言行。保留原标题/摘要/日期/可见范围/缩略图和图片错误回退。纪念日行与留言行使用非交互article，内部原查看/提醒开关分别操作，避免在button卡片中嵌套其他交互控件。提醒与留言原已读写入/当前内容核对仍保留。

## 布局保留范围

本批共用真实工厂和Card基础样式，既有模块类继续定位与呈现原稿；并未把所有局部CSS差异自动接受为最终例外。照片网格保留图像内框和双列规则；纪念日行保留文章外框与独立提醒开关，内部标题按钮不再额外形成卡片外框；主页与工坊近期横/纵向小卡保留所在原稿区域；其他列表保留动态滚动容器、元信息字号、摘要裁切。具体尺寸/颜色字面量是否映射共享Token仍需结合原稿逐页确认，不能仅凭类名或工厂调用声称视觉统一完成。

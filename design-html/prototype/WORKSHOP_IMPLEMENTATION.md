## 简单数据与模拟边界

`dujia-prototype-works`：id/type/sourceKind/sourceIds/name/story/style/mode/mood/characters/status/favorite/createdAt/updatedAt/startedAt/dueAt/willFail/completedAt。status为draft/generating/failed/ready。`dujia-characters`继续复用既有四字段键，生成时复制当前设定。未初始化作品集合为空，不补虚构作品。

PrototypeWorkshop集中all/find/put/route/editor/sources/draft/start/advance/refresh/scene/image/album；UI脚本只管理当前页。生成是本地有限状态演示，没有API、真实AI、后台推送或视频编码。八页分镜使用实际输入句子循环组合；无照片时保留原稿漫画插画，画风/模式作为参数和作品说明保存，尚未提供不同画风图像生成。影片播放是分镜轮播，不把它声称为真实影片文件。后续正式实现可按相同状态与数据合同接入服务。

保存相册使用浏览器Canvas构成900×1200 PNG，优先选用实际照片，未选照片使用原稿漫画区域；标题/正文可见。写入共享records集合，photo/workId/共同可见/已发布；在相册和详情中可以实际打开。删除工坊作品保留已输出照片。

素材来自已有shared published diary/photo和时刻集合；最多选择6条，Photo展示区为横向压缩布局，较多照片组合仍待复核。选择图片时只消费已有合格照片，不额外新增上传仓库。

## 失败演示与修复

session键`dujia-prototype-fail-next`支持work-generate/save/characters/album/delete/load。work-generate在提交时记录willFail，任务结束进入失败页，重试不自动再次失败。存储容量不足使用共享安全写入；输入和旧值保留。

- P0：生成中无终态 → 有限任务、成功/失败出口、离开恢复与取消草稿。
- P0：静态最近/作品列表与保存标记 → 实际集合、ID路由、相册输出记录。
- P1：素材类型只改变目的页面 → 实际共同素材选择，来源ID和正文用于当前创作。
- P1：页码只更新数字 → 更新对应场景文本；影片结果可播放/暂停片段。
- P1：新增作品列表拦截分类标签 → 内容区从20%移到28%，保留实施前失败证据workshop-tabs-blocked-regression.json。
- P1：取消确认时任务自动跳走 → 确认期间暂停进度跳转；测试跨越截止时间。
- P1：复制失败后弹层已关、文本不可选 → 重新打开可选链接Modal。
- P1：结果写入失败反复尝试 → 保持generating数据并提供显式重试保存。

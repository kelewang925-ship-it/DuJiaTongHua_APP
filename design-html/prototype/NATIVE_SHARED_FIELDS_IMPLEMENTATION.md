# 原画板字段接入共享行为

## 接入范围与API

114份原稿HTML中，29页声明了69个文本、密码、日期、原生Select或Textarea字段。DOMContentLoaded在现有控制器加载后使用既有`components.field({element})`接管这些节点。没有重建画板或替换节点；已有ID、name、值、maxlength、readOnly、disabled、选项、标签、监听器和父节点保持。没有标签的字段才补充名称。返回`{root:element,input:element,error,setError}`；root已在画板中，调用者不应再次append。重复接管同一节点返回同一对象。

普通`components.field({...})`继续创建标签/字段/错误组合供弹层使用。适配器复用同一个`fieldError`入口和input清错行为；原有aria-describedby保留并追加错误ID。现有显式错误目标仍优先。文件、颜色、滑杆、复选和单选控件继续原生专用语义，它们不属于文本字段工厂。动态日期弹层等非静态字段仍需补齐或明确保留理由。

原稿字段共享44px最小触摸尺寸。320px验证码格从42.08px补到44px，并缩小该宽度下的格间距；原字号、皮肤和选择器保持。普通有效状态只增加隐藏错误节点和语义属性。行内错误使用共同Token皮肤，定位到对应字段下方；与其他控件相交时尝试上方及可用横向空间，resize重算。没有可用上方区域时保留下方提示；完整逐页视觉与键盘验收尚未完成，不能据定位检查宣称全量无遮挡。

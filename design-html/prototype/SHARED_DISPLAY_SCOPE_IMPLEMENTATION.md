# 共同入口和个人展示范围

## 实际问题

16项初始同源基线全部失败，0脚本错误。首页／搜索显示其他已知作者的私密记录；共同相册只读存储visibility，来源已私密的衍生照片仍出现。私密详情／编辑缺少作者检查，照片与时刻发送期间来源变化后仍能保存共同留言。来源外部变化未刷新共同相册，未发送输入的范围标记也未更新。

首轮16项通过后补充来源恢复检查，20项中照片留言标题恢复失败；19/20结果保留shared-display-before-scope-label-restore。修复标题后，25项的五宽度热区检查发现照片编辑／更多只有40px；20/25结果保留shared-display-private-hit-area。现两处热区为44px，不降低测试阈值。

## 统一读取与操作

PrototypePreferences复用sharedContent、现有own昵称／别名合同，新增canView／visibleRecords／contentVisibility。来源不再共同使用的自有副本仍可个人访问，显示“仅自己可见”；已知其他作者的私密内容不进入首页、搜索、日记、相册，直接详情／编辑提供不可见状态与返回入口。无author的旧内容兼容当前本地用户，不证明真实账号权限。

共同相册Tab及范围筛选核对有效来源；首页／搜索标记有效范围。时刻列表按可访问性展示，私密时刻详情只显示个人范围，不提供共同留言；关联记录及共同留言聚合使用当前共同来源。过滤不改写或删除原正文和副本。

照片／时刻发送时重新核对当前共同来源，不可见则Toast并保留未发送文字。日记发送同样核对当前共同范围。只读相册／记录首页／时刻来源变化刷新；照片未发送草稿及打开的时刻回应Sheet保留输入、禁用发送，来源恢复共同后可继续发送。照片恢复时还原原标题。

# Export Rules

## General

- 保留原始比例、颜色和透明边缘。
- 禁止重新压缩已有 PNG。
- 禁止给插画和贴纸添加文字。
- 禁止用 CSS、Canvas 或 SVG 代码重绘已有插画。

## Formats

- 插画、贴纸、纹理：PNG。
- 图标：优先 SVG；现有 PNG 图标保持 PNG。
- 透明资源必须保留 alpha 通道。

## Figma

- Image fill 使用 `FIT`，除非资产明确要求平铺。
- Reference 中保留原始效果图，不裁切主体。
- 导出前检查 Asset Key、source path 和使用页面是否一致。

# 首页、相册与时刻的展示范围

Goal: 页面共同入口和共同留言使用当前来源范围；个人内容不被删除，已知其他作者的私密内容不展示。

Architecture: PrototypePreferences提供当前可访问记录与有效可见范围，复用上一阶段来源链。首页／搜索／日记／相册使用统一读取；照片与时刻留言提交前核对当前共同范围。只读来源变化刷新，编辑／未发送输入保留。无真实登录服务或双账号授权后端。

Ruling: 本地author与当前昵称／别名是现有个人记录合同；无author的旧内容保持当前本地用户兼容。不能将这种演示标为真实访问控制。现存不可共同使用的自有衍生副本仅个人展示，共同筛选不收录；不改写原文。

- [x] 统一可访问读取和展示范围，保留自己的副本和已删除祖先的既有合同。

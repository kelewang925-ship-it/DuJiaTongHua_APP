# 日记、照片、时刻编辑与留言已读

**Goal:** 编辑保存不覆盖别处的新正文，不复活已删除记录；新留言保留。聚合留言已读操作只修改当前留言，不使用旧整条内容写回。

**Architecture:** 复用 UI.read/write、PrototypeRecords 和既有未保存保护。提交时读取当前单条对象，比对原编辑内容（留言及更新时间除外）；内容竞争或删除则保持输入并提示重新核对。评论独立变化合并当前评论。已读操作读取当前共同范围、当前评论与当前路由，失败不导航。

**Tech Stack:** 原生 JavaScript、本地存储、现有 Playwright 页面验证。

**Spec:** design-html/prototype/STATE_RULES.md；当前完整交互原型目标。

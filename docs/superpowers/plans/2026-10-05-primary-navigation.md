# 一级导航补齐

当前源码搜索确认没有统一主导航，首页也没有宠物入口；实施前三项浏览器检查均失败（包括工坊失效作品顶部返回）。用户持续目标已授权补齐统一入口、返回和导航，本计划在当前隔离worktree执行。

## 设计

- 首页、重要时刻、工坊、宠物、我的共五个入口；回忆册继续由首页阅读卡进入。
- 在一级正常页及对应首次空状态页显示统一Bottom Tab；详情与编辑任务保持push和现有返回保护。
- 切换使用replace，不累积Tab历史；再次点击当前入口回到页顶。
- 同一入口使用同一目标；目标页的空/已有数据重定向由现有控制器决定。
- 导航位于原画板外，固定底部；body为它预留高度和安全区，原画板与底部按钮可完整滚动到导航上方。
- 原生线条SVG、现有颜色token、至少44px热区、明确名称、aria-current、键盘focus与现有减少动效规则。

## 验证

三项主流程由红转绿；九个一级/空状态/等待入口×五种宽度验证主导航和原页按钮命中、底部安全区、无横向溢出/脚本错误。当前114页空/有数据运行观察在改动前保存，改动后重新生成当前版本观察；静态/事件绑定清单不能当成逐控件验收。

# 胶囊衍生内容的共同可见范围

Goal: 现存来源改为私密、未开启、草稿或不可读时，衍生内容不能继续进入共同素材、共同备份或新的相册发布。

Architecture: 在既有PrototypePreferences中复用UI集合读取与健康检查，集中计算记录／时刻／作品的共同可见性。胶囊→时刻→作品→相册照片的现存来源逐层核对；循环引用不可用。宠物、回忆册、工坊复用同一读取规则，不修改存储中的原正文。已有删除合同仍保留独立收录时刻与已存相册照片；仅缺失可选祖先不自动删除独立副本。

Ruling: 来源变私密后，共同出口不得携带此前复制的正文。个人导出仍保留已有可访问内容；本地原型没有真实双账号权限实现。删除胶囊保留时刻、删除作品保留相册是已有明确用户流程，保持该行为。

Files: prototype-preferences.js、prototype-workshop-store.js、prototype-pet-life-store.js及只读页面storage观察；对应源绑定专项、必要消费者回归与实施记录。

- [x] 通过实际共同备份、素材选择、阅读／导出与发布操作复现衍生内容泄露，保留正常／删除合同对照。
- [x] 实施统一可见性读取；现存祖先不可见与循环拒绝，普通独立内容保持。
- [x] 工坊提交／存相册核对当前来源；失败保留原始内容与输入。
- [x] 来源外部变化时，回忆册／宠物只读展示刷新，编辑输入保留并在提交时核对。
- [x] 冻结源码，专项及直接消费者回归，HTTP与运行观察；记录范围和仍开放项，提交。

Validation: 实际按钮与下载内容检查；原始Storage不被隐私过滤改写；正常共同链、独立内容和已删除祖先对照；受损根与循环来源；外部变化后的页面与提交行为。全产品114页逐页终验继续。

验证结果：17项初始基线15失败／2对照通过；19项修复专项（含两条等待期间竞争），99项指定回归，共118项检查点通过。三项首次准备导航超时记录保留，15秒导航重跑组终态通过。228次运行观察0脚本错误与0未绑定候选。完整114页终验继续。

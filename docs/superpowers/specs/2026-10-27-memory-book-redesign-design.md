# 回忆册 V2：实体绘本与手机阅读体验设计提案

日期：2026-10-27。状态：用户已于 2026-10-27 确认方向并授权实施；实现和验证见 `design-html/prototype/BOOK_V2_IMPLEMENTATION.md`。

## 1. 意图与范围

用户希望以提供的约 29.8 秒视频为方向，重新设计回忆册的 UI、翻阅效果和手机操作，使它比现有版本更精致、有立体感，并适合日常使用。用户明确要求先联网研究、先设计。

本方案沿用现有共同回忆册业务，属于「扩展现有阅读体验 + 重构模块界面」，不是另建一套内容系统。新增的设计重点是实体封面、开合书、曲面翻页、纸张堆叠和适合手机的阅读/整理流程。

首版交付四张静态概念稿、完整交互提案与原有页面映射。概念稿中的人物、书名和记录均为虚构示例。静态图不能证明动画、触控热区、无障碍或性能已达标。自由手绘、无限画布、真实协同编辑、云同步、视频分享生成、真实 PDF 输出不纳入首版新增能力。

## 3. 视频观察与网络研究

## 5. 视觉方向：把两个人的日常，装订成一本实体绘本

### 5.1 延续与调整

保留奶油纸、可可棕、枯玫瑰、柔粉、手绘插画和情侣内容。把视觉重心从“背景里画着一本书”转为“用户正在操作一本书”。减少常驻的大号品牌标题、满屏花束、木架背景和重复装饰边框，给实际内容和书本留出空间。

- 书架：浅奶油环境、布纹封面、书脊、真实纸边与柔和落影；当前册占主位，相邻册部分露出。
- 阅读：奶油纸面，低对比玫瑰灰桌面。纸面主体近乎正视，仅纸边和翻动页面产生透视；休止状态不倾斜正文。
- 编辑/整理：平面纸张与清晰控件，保留品牌色；减少空间透视，确保操作位置稳定。
- 插画仅作为封面和具体内容的美术，不将用户照片默认改造成插画。概念稿的水彩示例不表示新增 AI 处理能力。

### 5.2 设计基准

| 项目 | 建议值 |
| --- | --- |
| 竖屏主基准 | 390×844 CSS px，另检查 320/375/414/430 宽度 |
| 页面左右边距 | 16；正文纸面内边距优先 20–24，窄屏可降至 16 |
| 正文 | 16px / 26px；大字阅读 20px / 32px；不要整体缩放书本来塞正文 |
| 标题/次级信息 | 24px 主标题、20px 页标题、14px 日期/说明；核心操作文字至少 14px |
| 字体 | 标题复用项目 Fairy/书卷气字体；正文优先清晰字体回退；加载完字体后再测分页 |

## 6. 信息架构与核心流程

不新增主 Tab。沿用现有首页和我的中的回忆册入口。

阅读主线：书架 → 点击封面从封面打开 / 点击继续翻阅定位上次内容 → 阅读 → 目录/书签定位 → 留补页 → 回到原页 → 合书回书架。

制作主线：书架新建 → 基础信息与封面 → 挑选共同素材 → 按素材建议模板 → 编辑当前页 → 整理章节和页序 → 保存成册 → 开始翻阅。

已有册编辑：书架“整理”或阅读“更多 → 整理书页” → 缩略图网格 → 单页编辑/移动/移除 → 保存 → 返回原阅读位置。读者与编辑者身份不新增权限规则，继续服从已有账号、共同可见性与业务约束。

## 7. 页面与操作设计

### 7.1 书架

顶部简洁“回忆册”栏和返回。首次有册时默认选最近阅读册；保留上次选册 ID，选择册不改变阅读位置。中部横向封面带只负责选册，当前册略大，两侧露出邻册。册数多时“全部回忆册”打开可滚动双列封面列表，不需要一册册滑过去。

当前册下显示书名、内容页数、章节数和上次位置。主按钮为“开始翻阅 / 继续翻阅”；次级操作“封面”“整理”；底部“新建回忆册”。点击封面从封面进入，点击继续则短过渡直达锚点，不让每次续读都重看全套开书动画。

全部册列表包含已发布、草稿、归档三个筛选，继续使用已有数据状态；书架主舞台只显示未归档的已发布册。首次空书架显示一本空封面和“制作第一本回忆册”，仅有草稿时明显提供“继续制作”，不伪造示例册。

### 7.2 沉浸阅读：竖屏

顶栏：返回书架、当前书名、更多。主区域为一张可读纸面，左侧窄书脊、右侧/下侧少量页边；内容图和文字在纸内排版，装饰不占正文区。顶部不重复大号品牌标题。

底部两层：上一页 / 当前位置 / 下一页；目录 / 书签 / 留一张补页。大字模式可简化为一层固定工具区，内容允许连续纵向滚动。工具栏占用的安全区与高度必须在分页前扣除。

点击正文空白可隐藏/显示工具栏；初次进入不自动隐藏，使用过之后仅在空闲时收起。点正文链接、图片、按钮或选中文字不触发隐藏/翻页。常驻显式返回入口在工具栏隐藏时可通过点空白恢复，系统返回始终可用。更多中提供大字连续阅读、整理书页、封面与主题、回忆册管理；真实未实现的导出格式不展示为可用。

### 7.3 横屏双页

在系统允许旋转且可用空间足够时展开为双页。建议初始门槛为扣除安全区和工具后，每纸面宽 ≥280 CSS px、高 ≥240 CSS px；达不到时维持单页，明确“单页阅读”，不压小正文。是否双页依实际空间和字号判断，不只看方向。

左右页使用同一套连续内容片段配对；允许照片跨页，但文字不跨书脊，人物关键区域避开中缝。旋转过程中回滚未完成的拖动，不提交翻页；以当前内容锚点重排，不能因奇偶页配对跳过内容。图像放大时先退出放大再切换显示布局。遵守系统旋转锁，不强制用户横屏。

### 7.4 目录与快速定位

底部“目录”和页码均打开同一 Bottom Sheet，支持章节、缩略图和书签三个视图，默认定位当前内容。章节列可折叠；缩略图是用于找内容的预览，正文不要求在缩略图中读完。

点项目后关闭面板并进入目标；从远处跳转使用短过渡，不逐页播放几十次动画。取消不改变位置。面板当前项需要可见焦点；没有书签给出“在阅读页点击书签收藏”。

### 7.5 整理书页

顶部返回/标题/保存；按章节显示双列纸面缩略图，窄屏与大字体可改单列。底部固定“添加回忆”和“管理章节”。当前设计稿为 24 页、3 章节的虚构示例，所有界面数据必须一致。

单击缩略图打开编辑；长按拖动调整章节内顺序。每页更多菜单提供编辑、上移、下移、移动到章节、从回忆册移除；键盘/读屏和不方便拖动的人都能完成同样操作。跨章移动用菜单，首版不要求长距离拖拽。

排序和移除只影响当前排列草稿，明确提示“改动将在保存后生效”。返回使用现有继续编辑/放弃保护。保存失败保留草稿；并发冲突沿用已有拒绝覆盖规则。移除确认写明不删除原始日记或照片；不承诺未实现的回收站或永久撤销。

### 7.6 建册、选材、编辑

用户依次完成“定封面 → 选回忆 → 排成书”。这是视觉上的三阶段，保留现有细分路由和稳定 ID，不在本轮直接合并或删除原有页面。

- 基础信息：书名默认空白，月份范围继续沿用真实校验；只在当前允许范围内预填。
- 封面：大预览、原有主题和真实共同照片入口。三种材质皮肤可研究映射到已有三主题，正式映射前核对主题原定义；不隐式改现有册主题语义。
- 选材：统一素材列表，按现有五类型筛选；下方固定已选数与下一步。月份无素材说明原因并提供调整范围或现有记录入口。
- 模板：按素材类型建议现有日记摘录、照片故事、重要时刻、工坊作品、宠物成长五种版式；章节扉页继续独立处理。不是新增无约束画布。
- 编辑：上部实时纸面预览，下部“内容 / 图片 / 装饰 / 版式”分区。点击预览文字进入对应编辑字段；键盘出现时收起大预览，保持输入和完成按钮可见。
- 图片裁剪继续保存焦点/缩放参数；换模板复用已有会话草稿。新增稳定长期编辑草稿不在首版承诺内，关闭会话前的保护与现状保持一致。
- 完成：轻量“已放入回忆册”，提供“继续添加 / 整理书页 / 开始翻阅”；不做长时间庆祝动画阻塞任务。

### 7.7 双人补页

阅读工具显示“留一张补页”，使用已有文字、表情、照片三方式，打开选择 Sheet 后进入现有编辑任务。完成后回原始内容锚点，纸面侧边出现可点开的补页签；有补页时仍可查看现有含补页阅读状态。

补页默认作为关联注笺，不自动增加全书物理页数，不改变原书页身份与他人的阅读位置。多人补页按已有数据顺序显示署名、日期和实际内容；概念稿不可伪造另一半已回应。共同回应关闭或来源不可见时，入口禁用并解释原因。

## 8. 手机手势与动效合同

| 操作 | 行为 | 防冲突与可替代方式 |
| --- | --- | --- |
| 书架横滑 | 切换当前册，落位后更新标题和按钮 | 普通滚动区域不接管；全部册列表可直接点击 |
| 阅读区域横拖 | 纸角/纸面随手指翻动，松手决定完成或回弹 | 链接、文本选择、控件和图片放大排除；保留系统边缘返回区；上下页按钮可替代 |
| 轻扫翻页 | 一次手势最多一页/一组双页，不积压长动画队列 | 动画中可快速结束到最近稳定页；不得漏页或重复持久化 |
| 点上一/下一页 | 播放同样的短翻页动效 | 不把整个左右半屏都做成不可见点击按钮 |
| 点页码/目录 | 打开同一定位面板 | 取消不改变位置，选择后直接定位 |
| 整理长按 | 拿起缩略图并拖动，落位后更新候选顺序 | 提供上移/下移/移到章节菜单 |
| 打开图片 | 明确放大按钮或图像操作入口打开独立图片查看 | 查看器内缩放/平移；返回才恢复翻页，不能一张图上同时争抢手势 |

初步参数仅供交互样机：横向移动超过 12 CSS px 且横向量大于纵向量约 1.4 倍后锁定翻页；拖动超过纸宽约 25% 或达到经实机验证的快速滑动条件后完成，否则回弹。最终值由不同设备实测调整。系统边缘手势优先，不设应用全屏强拦截。

动效分为：选中册轻微抬起 → 封面打开 → 纸张翻动 → 合书回位。点击翻页约 300–400ms，拖动直接跟手，松手收尾约 100–200ms；开合约 400ms，避免每次返回都等待长动画。重力感来自纸边、书脊遮蔽与随曲率改变的阴影，不依赖全屏粒子/持续摇晃。

普通模式追求柔性曲面翻页；不把单张矩形 `rotateY` 演示宣称为已还原视频。减少动态效果时改为 ≤100ms 淡切或即时切换，保留同样导航和位置。声音默认关闭，触感作为可选增强，不依赖其传达操作结果。

到最后一页保留页面，出现轻量“已经翻到这里了”及目录/返回书架/添加回忆入口；不能再一次误滑就强制退出。只有明确返回或选择合书才合上。

## 9. 内容分页、阅读位置与兼容

现有 `book.pages` 是业务书页；一条长正文可能对应多个阅读纸面。设计必须明确区分：业务页 ID、阅读片段、左右纸面与补页。

- 业务页 ID、来源引用、章节序列、书签与原始素材保持现有语义，不因换字号/横竖屏生成新的业务记录。
- 临时分页先测量可用纸面，段落/图片整体优先，过长段落允许在文本边界拆分；标题避免孤悬，图片保持比例，正文不截断。续页显示标题短标和“续”。
- 阅读锚点建议是业务页 ID + 文本/块定位；沿用 `lastPage` 存业务页兼容旧入口，新增可选锚点字段的迁移方式留给后续实施设计。旧册没有锚点时从该业务页开头恢复。
- 底部主计数继续用业务内容页，例如“第 6 / 24 页”；如拆分，另标“本页 2/3”。横屏同时呈现两条业务页时显示“第 6–7 / 24 页”；跨续页时以当前主锚点的业务页为准。书架 24 页与阅读计数保持一致。
- 封面、章节装饰扉页不静默加入业务页总数；若要把扉页变成可编排业务页，需要单独设计数据变更，首版用阅读装饰处理。
- 现有书签按业务页，首版继续跳该业务页起始片段；不假装精确到行。最近阅读可以用可选锚点恢复到片段。
- 连续大字阅读使用相同顺序与锚点，支持 16/20 两档及系统文字缩放；放大后重新测量，屏幕阅读器读到真实文本，不能只提供不可访问的整页贴图。
- 首次内容加载成功后才记录位置；完成翻页后写入，取消拖动不写入。失败显示“阅读位置未保存”，仍允许阅读并可重试，不能把失败当成功。
- 来源私密/删除后，重查共同可见性；当前及预载纸面、缩略图、纹理和导出均遮蔽关联内容与补页，保留已有独立文字。多窗口变化时重新检查，不只在首次打开时验证。

## 10. 状态与异常

| 状态 | 设计响应 |
| --- | --- |
| 没有册 / 只有草稿 | 空封面建册 / 明显继续草稿，不种植假数据 |
| 空白已建册 | 阅读入口导向“添加第一段回忆”或目录，不出现除零页码 |
| 加载慢或失败 | 书形占位 + “正在打开回忆”；失败可重试和返回，数据不被清空 |
| 图片失败 | 保留图片占位尺寸和说明，可重试，不挡住正文和翻页 |
| 来源不可见 | 说明关联内容不可见，保留独立文字；禁止查看关联补页 |
| 补页未开放 | 禁用入口且可查看原因，目录/阅读继续可用 |
| 保存失败 | 当前编辑/排列和图片仍保留；显示错误与重试 |
| 另一处更新 | 拒绝覆盖并保留本地候选；提供返回查看最新，不新增虚假的自动合并能力 |
| 当前册/页被删除 | 结束翻页，返回有效目录或书架，不显示陈旧缓存内容 |
| 低性能 / 减少动态效果 | 平面或淡切阅读，仍保留所有正文、导航和补页能力 |
| 长名称/大字/窄屏 | 标题可换行或视觉省略并可查看全文；控件不被挤出屏幕，网格可改单列 |

## 13. 后续验证与实施顺序

设计确认后先做独立交互样机，范围只含现有册 → 开书 → 前后页/拖动取消 → 合书 → 恢复位置。先验证 390 竖屏及横屏，再覆盖五宽度/系统缩放/减少动效/低性能设备。样机的目的包括决定曲面渲染技术，不在设计阶段仅凭静态图指定 WebGL 或引入依赖。

视觉核验：封面、纸张厚度、书脊、文字锐度、阴影方向、曲面正反面、露底与层级、横竖屏一致性。操作核验：首末页、连续快速滑动、回弹、左手/右手、系统边缘返回、弹层关闭、图片查看、键盘避让、目录定位、跨模式锚点和失败重试。回归现有书签、补页权限、素材遮蔽、排序保存、备份与全局继续阅读。

至少用真实手机验证手势与性能；浏览器截图不能代替。帧率/内存预算在样机选定目标设备后量化，本提案不承诺所有设备稳定 60fps。普通低端设备若无法保持平稳体验，应有用户可选择且功能完整的简化翻页模式。
